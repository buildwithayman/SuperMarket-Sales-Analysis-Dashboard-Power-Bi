# SuperMarket-Sales-Analysis-Dashboard-Power-Bi

📊 Super Store Sales Analytics & Forecasting Dashboard | Power BI

Data is most valuable when it helps businesses understand the present and predict the future.

I built this interactive Super Store Sales Dashboard in Power BI to analyze sales performance and forecast upcoming demand using historical data.

The dashboard consists of two analytical views that provide both descriptive and predictive insights for better business decision-making.

🚀 Dashboard Structure

🔹 Overview Page
Provides a complete sales performance summary including key KPIs and business insights.

🔹 Sales Forecasting Page
Uses Power BI’s time-series forecasting to predict sales for the next 15 days, helping businesses anticipate future demand.

📊 Key Business Metrics

💰 Total Sales: 1.6M
📦 Total Orders: 22K
📈 Total Profit: 175K
🚚 Average Shipping Days: 4

📈 Key Visualizations

• Sales by Region, Segment, and Payment Mode
• Monthly Sales & Profit trends (Year-over-Year)
• Sales distribution by Category & Sub-Category
• Shipping performance by Ship Mode
• Geographical sales analysis by state
• 15-Day Sales Forecast using time-series analysis

💡 Insights

• The West region generates the highest sales performance.
• Consumer segment contributes the largest share of revenue.
• Technology and Office Supplies dominate product sales.
• Sales forecasting helps anticipate upcoming fluctuations in demand.

⚙️ Tools Used

• Microsoft Power BI
• Power Query (ETL)
• Data Modeling
• DAX Measures
• Time Series Forecasting
• Interactive Dashboard Design

✨ This project demonstrates how data visualization combined with forecasting techniques can help organizations move from reactive to proactive decision-making.
